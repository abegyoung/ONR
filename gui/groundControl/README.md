2017 ONR flight ground control GUI.

Probably the last version for flight.

##start.py 
sends commands with the CSBF CIP 16-bit command set
up and down links are over serial to machine running gui

##start_ser.py
lab test.  sends commands with simple 0-15 numbering scheme over serial

##start_tcp.py
lab test.  sends commands with simple 0-15 numbering scheme over tcp to server
