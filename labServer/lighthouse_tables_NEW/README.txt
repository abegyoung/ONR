In this directory, I have various "TFA_altXX_1deg.txt" symlinked to 
appropriate files in the dir "TFA_tables/", etc.

Then, the "spiral" files are generated by an incantation like
$> cat TFA_alt??_1deg.txt > TFA_spiral_alt05-43_1deg.txt

Those symlink files are all generated by the shell scripts "symlink_TFA1.sh", etc.

Recommend that if you want to change the sets of files that are symlinked,
copy the .sh script, edit to your liking, and run that script, for easy 
resetting to other configs.
